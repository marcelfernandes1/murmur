Code signing policy
and privacy.

Signing is pending. Murmur’s Windows development builds are currently unsigned. The main website will offer an installer after trusted code signing is configured and verified.

Windows releases

Marcel Fernandes maintains the project, reviews changes, and approves releases. Windows packages are built from the public source repository using GitHub Actions. Capture, speech recognition, and cross-app paste checks must pass before release.

Published Windows installers must have a valid Authenticode signature and a trusted timestamp. Murmur’s own executables and libraries are checked separately from third-party dependencies. Release checksums are generated after signing. Windows releases use separate version tags so Mac updates keep working independently.

Your audio stays on your PC

The Windows app processes speech locally. It does not upload recordings or transcripts, collect analytics, or contact a transcription service. Recordings stay in memory and are discarded after use. A failed recording remains available to retry until you cancel, start another take, or quit.

Preparing a model downloads files from Hugging Face or GitHub over HTTPS. Those services receive ordinary connection information, including your IP address. Model files are checked against pinned SHA-256 checksums before loading. After setup, dictation and optional cleanup work offline. See Hugging Face’s privacy policy and GitHub’s privacy statement.

History, settings, and the clipboard

Settings, vocabulary, downloaded models, and optional transcript history are stored in %LOCALAPPDATA%\Murmur. History is local JSON and is not encrypted by Murmur. You can disable future history or clear saved transcripts in the app. Uninstalling preserves this data folder; delete it separately to remove it.

Recognized text is copied to the Windows clipboard and remains there after a paste. Other apps, or Windows clipboard history and sync if you enable them, may access clipboard contents. If you change the destination window or field, Murmur leaves the text copied instead of pasting into a different destination.

Microphone permission stays under your control in Windows Settings. Murmur never changes microphone permissions automatically and does not run with administrator privileges. Installing Microsoft’s Visual C++ prerequisite may request Windows administrator approval.

Preview testing

Automated tests run on Windows Server with a virtual microphone playing prerecorded speech. This checks the real Windows audio and paste APIs. Physical microphones, Bluetooth devices, Office, and hardware-specific behavior still require testing on Windows PCs.
